# Research-backed visual programming.

Anvaya's node-graph methodology is grounded in a peer-reviewed IEEE study (2026). The paper documents how visual programming surfaces measurably reduce the time required to scaffold REST APIs — with a measured **31–36% time reduction across an n=24 developer study (IEEE 2026 study)** — and what design choices keep the generated code idiomatic.

You can read the full paper here: [`/anvaya_ieee_format.md`](https://github.com/karnav018/anvaya/blob/main/anvaya_ieee_format.md). The repository copy is the canonical version; we will publish a hosted PDF once the proceedings are finalised.
