# FAQ

## Do I have to know how to code?

No, but Anvaya is built for developers who do. The generated code is yours to read and edit. Non-developers can certainly drive the canvas, but the output is plain Express.js — you'll get the most value if you can review and customise it.

## What frameworks do you support?

Today: **Node.js / Express**. Coming: FastAPI, NestJS, Go. Each new target is a code-generation backend swap — your canvases stay the same when we add more.

## Can I self-host the APIs?

Yes. Anvaya outputs a standard Node project. Deploy anywhere — Fly.io, Render, AWS, your laptop. There is no Anvaya runtime dependency, so if you stop using us tomorrow your API still runs.

## Is there a free tier forever?

Yes. The Free plan gives you 10 generations a month, indefinitely. You can build and edit unlimited canvases on Free — only generating the downloadable project counts against the quota.

## Can my team collaborate on the same project?

Yes, on **Pro and above**. Owners, editors, and viewers each have appropriate access; invites are sent by email and expire after seven days.
