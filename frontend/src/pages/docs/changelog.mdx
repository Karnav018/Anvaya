# Changelog

## v1.0 — initial launch (May 2026)

The first public release of Anvaya.

- Visual canvas with **14 node types**: Route, Auth, Database, Schema, Validation, Middleware, Response, Fetch, Cache, Email, Upload, AI, Payment, Error Handler.
- **Express.js code generation** with full project scaffolding — routes, models, middleware, validators, tests, `.env.example`, `README.md`, and a pinned `package.json`.
- **Teams** with owner / editor / viewer roles, invite flow, and workspace switching.
- **Stripe billing** with Free and Pro plans, quota enforcement, and a hosted billing portal for Pro customers.
